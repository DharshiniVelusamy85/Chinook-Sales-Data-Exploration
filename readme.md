# Chinook Sales Data Exploration
SQL portfolio project exploring sales data from the Chinook SQLite database using filtering, aggregate functions, joins, and business analysis.

## Overview

This project explores the Chinook SQLite database using SQL. It demonstrates core SQL concepts by analysing sales data through 25 business-focused queries.

The objective of this project is to strengthen SQL fundamentals while showcasing practical business analysis skills suitable for entry-level Data Analyst and Supply Chain Analyst roles.
